# Daily Sheet 실행 취소(`Cmd + Z`) 및 다시 실행(`Cmd + Shift + Z`) 사용 설명서 (DAILY_SHEET_UNDO_MANUAL.md)

## 📌 문서 개요
본 설명서는 **Daily Sheet** 그리드 시스템에서 지원되는 **실행 취소 (`Cmd + Z` / `Ctrl + Z`)** 및 **다시 실행 (`Cmd + Shift + Z` / `Cmd + Y`)** 기능의 대상 작업 목록과 작동 원리를 명확히 안내합니다.

---

## 1. ⌨️ 단축키 안내

| 기능 | Mac 단축키 | Windows / Linux 단축키 | 비고 |
| :--- | :--- | :--- | :--- |
| **실행 취소 (Undo)** | `Cmd + Z` | `Ctrl + Z` | 직전 작업 취소 및 이전 상태 원복 |
| **다시 실행 (Redo)** | `Cmd + Shift + Z` 또는 `Cmd + Y` | `Ctrl + Shift + Z` 또는 `Ctrl + Y` | 취소했던 작업 재적용 |

> 💡 **참고**: 텍스트 상자(`textarea`/`input`) 안에서 글자를 직접 타이핑하는 중에는 브라우저의 글자 단위 기본 Undo가 동작하며, 셀 입력이 완료(Enter, Tab, Blur 등)된 후부터 그리드 레벨의 `Cmd + Z` 작업 취소가 적용됩니다.

---

## 2. 📋 `Cmd + Z` 지원 작업 대상 목록

Daily Sheet에서 수행되는 아래의 모든 주요 편집 및 일괄 조작에 대해 `Cmd + Z` 실행 취소가 완벽히 지원됩니다:

### 1) 셀 직접 수정 / 입력
- **단일 셀 입력 및 수정**: 출결, 오늘TEST, 점수, 오늘할일(To-Do), 완료한일, 오늘숙제, 다음TEST, 학생미션, 메모, 주의점 등 각 셀의 내용을 입력/수정한 후 취소할 수 있습니다.

### 2) 일괄 조작 및 복사 / 붙여넣기
- **아래로 채우기 (`Cmd + D` / `Ctrl + D`)**: 위쪽 셀의 내용을 아래 셀 범위로 일괄 복사해 채운 직후 `Cmd + Z`로 한번에 취소할 수 있습니다.
- **클립보드 붙여넣기 (`Cmd + V` / `Ctrl + V`)**: 엑셀이나 외부에서 복사한 다중 셀 테이타를 붙여넣은 직후 `Cmd + Z`로 원상복구할 수 있습니다.
- **범위 및 단일 셀 삭제 (`Backspace` / `Delete`)**: 단일 셀 또는 마우스 드래그로 선택한 다중 셀 범위의 내용을 지운 후 `Cmd + Z`로 이전 입력 데이터를 즉시 복원할 수 있습니다.

### 3) 🪄 주의점 칼럼 헤더 수동 이월
- **주의점 최신 메모 수동 불러오기 (`🪄` 버튼)**: 주의점 헤더의 요술봉 버튼을 눌러 비어있는 학생들의 주의점 칸에 과거 최신 메모를 일괄 불러온 후, `Cmd + Z` 한 번으로 0.1초 만에 깔끔하게 취소하여 다시 빈 칸 상태로 돌릴 수 있습니다.

### 4) 🏷️ 태그별 일괄 입력 모달 (`TagBatchInputModal`)
- **태그/선택 학생 일괄 입력**: 태그 모달을 통해 가, 나, 다, 라 그룹이나 특정 선택 학생들에게 오늘TEST, 숙제, To-Do 등을 한꺼번에 작성한 후 `Cmd + Z`로 수십 명의 변경 사항을 한번에 취소할 수 있습니다.

### 5) 📋 엑셀 / ACA2000 일지 데이터 파일 복원
- **엑셀 일지 데이터 가져오기 (`useTodaySheetImport`)**: ACA2000이나 엑셀 파일 업로드를 통해 당일 일지 데이터를 일괄 불러온 직후, 잘못 불러온 경우 `Cmd + Z`로 가져오기 실행 이전의 원래 일지 데이터로 복구할 수 있습니다.

## 3. ⚙️ 데이터 및 성능 보장 원칙

1. **초고속 경량화 Diff 처리**:
   - `Cmd + Z` 실행 시 전체 학생 세션 데이터를 통째로 교체하지 않고, **변경된 필드의 차이점(Diff)**만 경량화하여 처리하므로 렉이나 화면 흔들림 없이 0.1초 만에 즉시 취소/재적용됩니다.
2. **4단계 실시간 일체화 Sync**:
   - `Cmd + Z` 실행 시 **DOM ➔ 자식 State ➔ 부모 State ➔ Supabase DB** 4단계가 동시에 동기화되어 새로고침 없이 화면에 즉시 반영됩니다.
