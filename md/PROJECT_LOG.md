# Hokma 수학 (Hokma Math) 관리 플랫폼 프로젝트 기록

이 문서는 'Hokma 수학' 학원 운영 앱의 개발 과정과 계획을 기록하여, 여러 에이전트가 협업할 때 일관성을 유지하기 위해 작성되었습니다.

## 1. 프로젝트 개요
- **이름**: Hokma 수학 (Hokma Math) - 일시적으로 OneGlance로도 지칭됨.
- **목표**: 원장님과 선생님의 업무 효율을 극대화하는 '한눈에 파악되는' 학원 관리 SaaS.
- **핵심 철학**:
  - **One-Glance**: 대시보드에서 모든 상황 즉시 파악.
  - **Minimal Click**: 모든 자료와 기록에 1~2단계 클릭으로 도달.
  - **Individualized**: 개별 진도 수업에 최적화된 시각적 관리.

## 2. 주요 기능 (핵심 요구사항)
- **통합 대시보드**: 요일/학년/학교/선생님별 다중 필터링 지원.
- **5회차 브리핑**: 학생별 최근 5번 수업 상태(숙제/출석/지각) 시각적 요약.
- **유닛 블록 진도**: 구글 시트 데이터 기반 가로 스크롤형 단원 관리.
- **페이지 기반 과제 자동화**: 시작/끝 페이지 입력 시 주제 자동 추출.
- **스마트 PDF 창고**: 단원 연동 추천 및 고속 검색이 가능한 서버 내 자료 저장소.
- **테스트 레드라이트**: 단원 종료 시 테스트 필수 알림 및 상태 하이라이트.

## 3. 기술 스택 (Tech Stack)
- **Frontend**: Next.js (App Router), React, Tailwind CSS, Framer Motion.
- **Backend/DB**: Supabase (Auth, RLS 적용).
- **Automation**: Google Sheets API (교재 데이터 연동), 향후 AI 연동 계획.
- **Infrastructure**: 로컬 WiFi 서버 운영 예정 (보안 및 저작권 파일 관리 목적).

**에이전트 가이드 (개발 원칙)**:
1. **고급스러운 디자인**: 프리미엄 SaaS 수준의 에스테틱 유지.
2. **모듈화(Modular)**: 모든 신규 기능은 `components/` 폴더 내 독립된 파일로 작성하며, `page.tsx`는 컨테이너 역할만 수행한다.
3. **타입 안전성**: `types/` 폴더에 공통 인터페이스를 정의하여 데이터 일관성을 유지한다.
4. **One-Glance**: 모든 정보는 한눈에 파악 가능해야 하며, 상세 정보는 점진적 노출(Progressive Disclosure) 방식을 취한다.
5. **Admin-Led Auth**: 학생은 직접 가입하지 않으며, 관리자가 등록 시 생성된 정보를 통해 로그인한다. (전화번호 뒷자리 등 활용)

## 9. 로컬 PDF 자료 창고 설계 (Smart Library)
- **대상**: 초등부, 중등부, 고등부 전 학년 자료.
- **주요 테스트 유형 (3대장)**:
  1. **단원평가 (Chapter Test)**: 평소 진도용, 교재별 단원 마무리.
  2. **주간테스트 (Weekly Test)**: 매주 학습 성취도 점검용.
  3. **기출문제 (Past Exam)**: 시험 대비 기간용 (1/2학기 중간/기말).
- **폴더 체계**: `[학부]/[학년 or 과목]/[유형]/[ID]_[파일명].pdf` 구조 지향.
- **Test ID 규칙**: 
  - 4~5자리 가변 자릿수 허용 (최종 단계에서 자릿수 통일 권장).
  - 대역별 유형 구분 (예: 1번대-단원, 3번대-주간, 7번대-기출).
- **기능 연동**:
  - `TodaySheet`에서 ID 입력 시 로컬 서버의 PDF 자동 매칭 및 퀵 프리뷰/인쇄 지원.
  - 학생 포털에서 본인이 치른 시험지 PDF 열람 기능 제공.

## 12. PDF 교재 분석 및 구글 시트 데이터화 가이드
향후 교재 데이터 확충 시 다음의 표준 절차를 준수한다.

### ① 환경 설정 및 도구
- **필수 라이브러리**: `pypdf` (Python)
- **설치**: `python3 -m pip install pypdf --user --break-system-packages`

### ② 분석 프로세스
1. **코드 매칭**: 구글 시트 `master` 탭에서 대상 교재의 `bookcode`를 먼저 확인한다. (예: `rpm-gt1`, `rpm-ds`)
2. **텍스트 추출**: PDF의 6~15페이지(목차 영역)에서 단원명과 시작 페이지 정보를 추출한다.
   ```bash
   python3 -c "import sys; from pypdf import PdfReader; reader = PdfReader('파일경로.pdf'); [print(f'--- Page {i+1} ---\n', reader.pages[i].extract_text()) for i in range(5, 14)]"
   ```
3. **데이터 가공 원칙**:
   - **시작 페이지**: 첫 단원의 시작은 반드시 **1페이지**로 설정한다. (표지 및 목차를 포함하여 선생님의 숙제 범위 입력 편의성 제공)
   - **단원명**: `01. 단원명` 형식을 유지한다.
   - **끝 페이지**: 다음 단원의 시작 페이지 바로 전 페이지로 설정한다.

## 20. 로컬 학원 전용 데스크톱 패키징 및 독립 DB 아키텍처 전략 (2026-08-29)

클라우드 SaaS(Vercel + Supabase) 형태 외에도, 특정 학원에 **"독립 설치형 로컬 프로그램 + 맥미니 중앙 DB"** 형태로 공급 및 납품할 수 있는 기술 아키텍처입니다.

### ① 데스크톱 단독 실행 프로그램 패키징 (`.app` / `.exe`)
- **기술 스택**: **Electron** 또는 **Tauri**
- **동작 방식**: Next.js / React / TypeScript 기반 소스코드를 그대로 패키징하여 윈도우용 `Setup.exe` 및 맥용 `.app` / `.dmg` 파일 생성.
- **장점**:
  - 브라우저 주소창 없이 학원 전용 아이콘과 단독 창으로 깔끔하게 실행.
  - 내 소스코드가 노출되지 않고 안전하게 암호화/바이너리 형태로 보호됨.
  - 별도 프론트엔드 재개발 없이 현재 웹 코드를 100% 재사용.

### ② 학원 맥미니(Mac mini) 중앙 서버 & 로컬 DB 구축 방식
학원 카운터의 맥미니를 중앙 서버로 두고, 데이터베이스까지 맥미니 하드디스크에 완전히 격리하는 3가지 방식:

1. **로컬 Supabase (Docker 기반) — 가장 권장 ⭐⭐⭐**
   - 오픈소스 Supabase를 맥미니 로컬에서 구동 (`npx supabase start` 또는 Docker).
   - **코드 변경 0%**: 기존 Supabase API 호출, Realtime 실시간 동기화, PostgreSQL 스키마를 단 1줄도 고칠 필요 없이 `NEXT_PUBLIC_SUPABASE_URL`만 맥미니 로컬 IP(`http://192.168.0.x:54321`)로 지정하면 완료.
2. **단일 파일 SQLite DB (`academy.db`) — 무설치 초경량**
   - 별도 DB 서버 프로세스 없이 `academy.db` 파일 하나에 전체 학생/시간표 데이터를 저장하여 복사/백업(USB 백업) 용이.
3. **macOS Postgres.app — 네이티브 PostgreSQL**
   - 맥 전용 Postgres 데몬을 상시 구동하여 연결.

### ③ 맥미니 독립형 내부망(LAN) 운영의 핵심 이점
```
[ 학원 내부 Wi-Fi / 유선망 ]
         │
         ├── 🍏 맥미니 (카운터 중앙 허브)
         │     ├── 1) 로컬 DB (맥미니 하드디스크에 학생 데이터 안전 보관)
         │     └── 2) 학원 프로그램 (.app / Next.js Server) 상시 구동
         │
         ├── 📱 선생님 A 태블릿 (학원 Wi-Fi 접속 → TodaySheet 실시간 작성)
         ├── 📱 선생님 B 태블릿 (학원 Wi-Fi 접속 → 진도/숙제 실시간 작성)
         └── 💻 원장실 PC (학원 Wi-Fi 접속 → 전체 일지 및 시간표 모니터링)
```

1. **외부 인터넷 단선 무적**: KT/SK 등 외부 통신사 인터넷이 일시적으로 끊겨도, 학원 공유기(Wi-Fi)만 켜져 있으면 100% 정상 작동.
2. **완벽한 데이터 보안 & 개인정보 보호**: 학생 개인정보 및 상담 일지가 외부 클라우드로 전송되지 않고 학원 내부 기기에만 영구 보관.
3. **클라우드 비용 0원**: Vercel/Supabase 등 외부 유료 SaaS 구독료 없이 평생 무료 운영 가능.
4. **초고속 응답 속도**: 내부 LAN 통신으로 네트워크 지연(Lag)이 0에 수렴.
